# Baccant

Sito statico multipagina per il noleggio di attrezzature professionali in provincia di Lecce.

## Struttura

- `index.html` — homepage
- `prodotti.html` — catalogo
- `deumidificatore-master-dh62.html` — pagina prodotto
- `come-funziona.html` — processo di noleggio
- `contatti.html` — contatti e WhatsApp
- `assets/css/style.css` — stile condiviso
- `assets/js/main.js` — menu mobile e tracciamento WhatsApp

Il sito non richiede build, database o dipendenze: basta pubblicare la cartella così com’è.
